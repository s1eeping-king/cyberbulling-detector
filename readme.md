# 多模态网络霸凌检测

## 项目结构

### 主要目录说明

- `data/`: 存放所有数据文件
  - `processed/`: 预处理后的数据，包括特征向量和标记数据
  - `label_data/`: 标注数据，包含霸凌和情感标签
  - 其他数据文件：原始的视频、评论和用户数据

- `knowledge_graph/`: 知识图谱相关代码和数据
  - 知识图谱构建、验证和分析工具
  - 图数据处理和特征提取
  - `knowledge_graph.pkl`: 构建好的知识图谱文件

- `GCN_complex_fusion/`: 复杂图卷积网络模型
  - 包含多模态特征融合
  - 使用GCN进行图结构学习
  - 实现了复杂的注意力机制

- `GAT_model/`: 图注意力网络模型
  - 基于GAT的霸凌检测模型
  - 包含注意力机制的实现
  - 模型训练和评估代码

- `GCN_simple/`: 简单图卷积网络模型
  - 基础GCN模型实现
  - 用于对比实验

- `try/`: 实验性代码和测试
  - 包含各种模型的实验版本
  - 用于测试新功能和改进

- `neo4j_import/`: Neo4j数据库导入文件
  - 用于知识图谱可视化
  - 数据库导入脚本
